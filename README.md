# React To-Do Management App

React + React Router + Axios + JSON Server CRUD application.

## Features

- View all todos
- Add a new todo
- Edit todo title/status
- Delete todo with confirmation
- React Router navigation
- JSON Server REST API

## Setup

### 1. Install dependencies

```bash
npm install
```

### 2. Start JSON Server

```bash
npm run server
```

API:
http://localhost:3000/todos

### 3. Start React

Open another terminal:

```bash
npm run dev
```

Application:
http://localhost:5173/todos

## Routes

- `/todos`
- `/add-todo`
- `/edit-todo/:id`
